# ROCKET — Knowledge Package

Everything a human or an AI needs to answer **any** question about ROCKET itself —
its systems, economy, content and behavior — lives in this folder.

## Index

| File | What it is |
|---|---|
| [knowledge.md](knowledge.md) | **Start here.** Complete reference: answer pipeline, XP economy, quests, missions, shop, catalogs, detection, online AI, persistence, known quirks |
| [codex.md](codex.md) | **The Order of the Eternal Codex** — the medieval-scholarly progression layer: ranks, lore realms, quest disciplines, Rocket's desk, chronicle & audit log |
| [rules.json](rules.json) | Machine-readable mirror of every system, formula, constant and catalog — **generated from live code** by `cargo test` (`src/docs_gen.rs`), cannot drift |
| [schema.json](schema.json) | JSON Schema describing rules.json's structure |
| [games.json](games.json) | Game registry (166 games) + per-game knowledge-base stats — generated |
| [faq.md](faq.md) | Player-style questions, answered from the formal rules |
| [strategy_notes.md](strategy_notes.md) | XP-optimization math, coin strategy, progression routes |
| [changelog.md](changelog.md) | Versioned history, marked current vs historical |

Related artifacts outside this folder:
- `rocket-qa-report.md` (project root) — verbatim Q&A from the live answer pipeline,
  fact-checked (generated by `cargo test`, see `src/game_qa.rs`)
- `README.md` (project root) — user-facing quick start

## Regenerating

```bash
cargo test          # regenerates docs/rules.json, docs/games.json AND rocket-qa-report.md
```

The generator test also asserts the hand-written files exist — deleting any of them
fails the suite. When code changes a rule, the JSON updates automatically; update the
matching section in knowledge.md in the same change set.
